GDS Lens — several viewers on one page

Each <gds-lens> below drives its own viewer: its own shadow tree, its own WebAssembly instance, its own WebGL2 context. They share nothing — layer properties, marker databases and saved views all belong to the viewer they were given to, and the saved ones are kept under each element's id. The first three load a layout up front; the last three wait for you. Pan with the mouse, zoom with the wheel, and drop a layout file on any of them.

On demand — viewer created on click

The five above hold a WebGL2 context from the moment they mount. This card creates no element until you ask, and destroy() gives the context back — what a page with more layouts than contexts wants.

Six live viewers is close to the ceiling: browsers cap WebGL2 contexts per page at roughly 8 to 16, and past that they start dropping the oldest. A page showing a dozen layouts wants one viewer swapping layouts, or card 6's create-and-release pattern.

Serve the repository root over HTTP and open /examples/multi-view.html: this page imports the built bundle from dist/ and its layouts from test/fixtures/, and a module import will not run from file:// at all. Run npm run build first, then, for example, python3 -m http.server 8000 and open http://localhost:8000/examples/multi-view.html.
